PolliCraft

Pollinations AI for your Minecraft server: talking villagers, prompt-to-map pictures and chat answers, paid with your own Pollen.

What players see

> /polli npc create Greta blacksmith

[Polli] Spawned Greta (blacksmith). Right-click to talk.

[Polli] You are now talking to Greta. Type in chat, or bye to stop.

Greta: Ah, traveler—keep your boots off my forge floor. Name’s Greta, blacksmith of this village; if you’ve got iron to spare, I’ll gladly help you hammer it into something worth your while.

Steve_Tester > Greta: Can you fix my iron pickaxe? What do you need for it?

Greta: Aye, I can fix it—bring the iron pickaxe and tell me what it needs: if it’s just durability, I’ll need extra iron (and maybe some coal/XP to mend it).

Steve_Tester > Greta: Thanks! And what is better, diamond or netherite?

Greta: Diamond’s tough, but netherite’s the real prize—stronger and more resistant, and it laughs at lava better too.

Features

Villagers that talk. Each one has its own persona and memory. Right-click and type in chat; players nearby hear the answers.
Your own personas. Blacksmith, librarian, farmer and guide built in, or write one: /polli npc create Jack a grumpy pirate.
Prompt to map. /polli image <prompt> paints a filled map for an item frame. Saved across restarts.
Any live model. Pick any text or image model from the live lists; /polli models shows them in game.
Your own Pollen. One API key in config.yml. Cooldowns, token caps and permissions keep spending in check.
Paper, Folia, Spigot. Async HTTP; results run on the right region thread on Folia.

Install

  1. Download the latest PolliCraft jar and drop it into plugins/.
  2. Start the server once to create plugins/PolliCraft/config.yml.
  3. Create a key at enter.pollinations.ai/keys and paste it in: 
    api-key: "sk_..."
text-model: "openai"
image-model: "flux"
  4. Run /polli reload and try /polli ask hello.
